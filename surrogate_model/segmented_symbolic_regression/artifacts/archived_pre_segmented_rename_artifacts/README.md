# Archived Pre-Segmented-Rename Artifacts

This folder contains segmented symbolic regression artifacts created before
the project renamed the old `symbolic_regression` workflow to
`segmented_symbolic_regression`.

These directories are retained for traceability only:

- `wool_symbolic_pysr_segments_runs`
- `wool_symbolic_candidate_evaluation_runs`
- `wool_symbolic_dataset_inspection`

Current segmented SR training and evaluation scripts do not write here. Their
default output roots are:

- `../wool_segmented_symbolic_pysr_runs`
- `../wool_segmented_symbolic_candidate_evaluation_runs`
- `../wool_segmented_symbolic_dataset_inspection`
